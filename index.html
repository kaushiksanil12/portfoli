                    Perspective

Approach

                        

                            High-performance data systems demand deep execution-level understanding. In distributed computing with PySpark and Databricks, I architect workflows around the Spark engine's core mechanics—optimizing DAG execution, minimizing wide transformation shuffles, enforcing partition pruning, and utilizing broadcast hash joins to prevent data skew and out-of-memory errors.
                        

                        

                            In data warehousing, I structure analytics layers using Kimball dimensional modeling (Fact tables, Dimension tables, and Slowly Changing Dimensions Type 1 & 2) alongside multi-hop Medallion Architecture (Bronze raw ingest → Silver cleansed/deduplicated → Gold analytical marts). Every pipeline is hardened with Terraform Infrastructure as Code and deep observability to guarantee deterministic, auditable data products.
